Household Finance Planner — public demo

What's here
  index.html   The whole app with a made-up household (Jordan & Taylor). Runs in the browser only.
  vercel.json  Small Vercel settings (security headers). Optional.

Nothing a visitor types is saved or sent anywhere. Reloading the page starts the demo over.
The sample data always lines up with the visitor's current month.

Deploy on Vercel (pick one)
  A) Vercel CLI: open a terminal in this folder and run   npx vercel --prod
     Accept the defaults (no build command, output directory = this folder).
  B) GitHub: put these files in a new repo, then in Vercel choose Add New → Project → import the repo.
     Framework preset: Other. No build command needed.
